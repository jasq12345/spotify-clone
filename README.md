# spotify-clone

```
backend/   FastAPI
frontend/  HTML + JS
```

## Backend

```bash
cd backend
uv sync
uv run uvicorn main:app --reload
```

API: http://127.0.0.1:8000 (docs: http://127.0.0.1:8000/docs)

## Frontend

Plain HTML/JS — open `frontend/index.html` in a browser or serve it with any static server.
